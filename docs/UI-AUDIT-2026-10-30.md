# Pre-client UI/UX, design-system and accessibility audit

**Date**: 2026-10-30 · **Branch**: `feat/bilingual-en-ar-website` · **Status**: changes are in the working tree, nothing committed or pushed. No database or schema change.

## How it was checked
- Crawled 29 routes (EN + AR, plus a 404) in the browser pane at 1440, 768 and 390 px wide (iframes sized to the width; 390 gives a 375 px layout once the scrollbar is counted). axe-core 4.10 (WCAG 2.0/2.1/2.2 A+AA and best-practice) was run on every one: 58 runs before, 12 targeted runs after the fixes.
- A custom script measured horizontal overflow, heading order, `<main>` count, unlabeled controls, missing alt, tiny text, 24 px targets and text contrast. Palette contrast was calculated by hand (below) because axe cannot see placeholders or semi-transparent colours.
- Keyboard, focus return and Esc were exercised with real key presses on the gallery lightbox, the mobile menu and the Branches dropdown.
- `npx tsc --noEmit` and ESLint over `app components lib hooks context tests scripts`: clean. All 23 test files under `tests/` pass.

## Flat page gallery
- **Cause**: `inventory-service` uses the row's `images` array and only falls back to sample photos when it is empty. Every row had one image, so one photo showed.
- **Now** (`components/rooms/room-gallery.tsx`): one large photo plus four tiles (stacked under the photo on phones, beside it from 768 px), fixed aspect ratios, "View all N photos", `+N` on the last tile if there are more than five.
- **Photos**: the flat's own photos come first and untouched. Only while a flat has fewer than five, representative interiors (bedroom, kitchen, bathroom, flat-type living area, branch interior; from `public/images`, same warm style, no exteriors or other cities) fill the gap. They are flagged: alt text says "Representative …", and a one-line note appears under the gallery and in the lightbox. Uploading five real photos in Admin → Inventory removes all stand-ins automatically; **admin upload, reorder, cover and remove are unchanged** and still drive this page.
- **Lightbox** (`components/media/photo-lightbox.tsx`, Base UI dialog, shared with the branch carousel): focus trap, Esc, ←/→ (mirrored in Arabic), Home/End, swipe, thumbnail strip, focus returns to the tile that opened it. Verified with real key presses.
- **Missing images** (`components/media/safe-image.tsx`): a failed photo is swapped for the default flat photo, and if that fails a neutral block is drawn. Verified by forcing an error event.
- Logic is in `lib/carousel/gallery.ts` (`padGalleryWithPlaceholders`), unit-tested; `buildGalleryItems` and its test are untouched.
